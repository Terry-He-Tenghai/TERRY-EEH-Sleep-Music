## 项目概述

Terry 是一个基于脑电波（EEG）的智能助眠音乐系统。系统实时采集用户的脑电信号，通过机器学习分类识别睡眠状态（清醒/浅睡眠/深睡眠），并自动播放相应的助眠音乐。

**技术栈**：
- 后端：Python + FastAPI + scikit-learn + MNE
- 前端：Vue 3 + Vite + Web Audio API
- 硬件：LK-Mini 16通道脑电采集帽
