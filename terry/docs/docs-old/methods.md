# 第一阶段研究方法草案

## 研究目标

本研究利用ANPHY-Sleep公开高密度睡眠脑电数据，验证预设的睡眠友好型16通道布局能否提取具有神经生理可解释性的W–N1–N2入眠动态、识别当前入眠状态，并预测受试者是否会在未来5分钟内首次进入稳定N2睡眠。状态分类描述受试者当前所处位置，转变预测描述其发展方向，区域频谱动态用于解释两者的神经生理依据。

## 数据来源

ANPHY-Sleep论文描述29名20–44岁健康成人的整夜多导睡眠记录；当前OSF公开文件中缺少EPCTL08，本次可下载并纳入28名。原始数据包括83通道头皮EEG、EOG、EMG、ECG、AASM人工睡眠分期以及伪迹检测矩阵，原始采样率为1000 Hz。本研究仅使用预设16通道：

`Fp1、Fp2、F3、F4、F7、F8、Fz、C3、C4、Cz、T7、T8、P3、P4、O1、O2`

ANPHY采用旧版命名T3/T4，本研究按国际10–10系统等价映射为T7/T8。研究不构建83通道模型，也不进行16与83通道性能比较。

## 入眠终点

考虑到N1具有明显的亚稳态特征和较低的评分者一致性，本研究将首次连续两个30秒N2 epoch的起始时刻定义为“首次稳定N2”。每名受试者截取该时刻前20分钟至后10分钟的EEG。若记录起点距离稳定N2不足20分钟，则保留所有可用的入眠前数据。

## 信号预处理

16通道信号使用平均参考，离线降采样至250 Hz，先通过50 Hz IIR工频陷波器，再通过四阶Butterworth 5–50 Hz带通滤波器。在线流式接口要求设备直接提供250 Hz数据，以避免在线重采样与离线重采样产生不同延迟。伪迹控制结合ANPHY提供的通道×30秒epoch伪迹矩阵和窗口级振幅规则。峰峰值超过500 μV、近似平坦或有效通道比例低于75%的窗口被标记为无效。

信号以6秒窗口分段，步长为3秒。所有在线候选特征仅由当前或历史窗口计算，不读取未来信号。

## 可解释特征

使用Welch方法估计每个窗口、每个通道的功率谱密度，提取delta（0.5–4 Hz）、theta（4–8 Hz）、alpha（8–12 Hz）、sigma（12–16 Hz）、beta（13–30 Hz）及high-beta（20–30 Hz）功率。

主要分析使用频带内PSD积分所得绝对功率的log10变换。相对功率仅作为补充，因为其组成约束可能使一个频带的增强被动表现为其他频带比例下降。有限窗口总能量依赖窗口长度，因而不作为主要跨阶段指标。

主要区域指标包括：

- 额区beta：Fp1、Fp2、F3、F4、F7、F8、Fz平均；
- 枕顶区alpha：P3、P4、O1、O2平均；
- 中央区theta和sigma：C3、C4、Cz平均；
- 额中央delta：额区与中央区通道平均；
- 枕顶alpha/中央theta的对数功率比；
- 上述指标仅基于过去60秒计算的变化斜率。

在线解释性Z分数以每名受试者分析片段最初5分钟的中位数和MAD进行稳健基线标准化。组水平配对统计另使用每名受试者最早可用的5分钟有效入眠前数据，并限制在N2前5分钟以前。中央区spindle由C3、C4、Cz检测，仅作为N2建立的描述性结果，不进入未来N2预测模型，避免循环论证。

## 统计假设

1. 随稳定N2临近，额区beta功率下降；
2. 枕顶区alpha随稳定N2临近而衰减，并探索其是否存在二次非线性；
3. 中央区theta随稳定N2临近而上升。

先将重叠窗口聚合为受试者×分钟均值，再使用线性混合效应模型检验beta和theta的时间趋势，并使用包含一次项与二次项的混合效应模型探索alpha非线性，受试者作为随机截距。另比较每名受试者最早可用的5分钟有效入眠前数据与N2前5分钟；基线窗口被限制在N2前5分钟以前，避免两段重叠。报告配对效应量Cohen's dz、bootstrap 95%置信区间及配对检验结果。混合模型、配对检验和通道级地形图分别在各自检验族内使用Benjamini–Hochberg FDR校正。

## 未来N2预测

预测任务定义为：当前窗口结束后0–5分钟内是否到达首次稳定N2。仅使用稳定N2之前的有效窗口。

主要模型为Logistic Regression，Random Forest和线性SVM作为比较。输入包括额区beta、枕顶alpha、中央theta/sigma、额中央delta、alpha/theta以及对应的过去1分钟变化斜率。模型采用按受试者留一交叉验证；标准化仅在每个训练折内拟合。

评价指标包括AUC、平衡准确率、灵敏度、特异度、F1以及连续30秒超过阈值时的提前预警时间。

主预测评价使用从记录起点开始、延续至稳定N2的连续特征流，分析起点不由未来N2时刻确定。另比较仅经过时间、仅当前AASM状态、静态EEG、静态EEG加过去1分钟动态以及动态EEG加经过时间的模型。除窗口级AUC和平均精确率外，报告目标5分钟事件检出率、提前时间和目标区间以前的每小时误报。

## W/N1/N2状态分类

AASM人工标签以30秒epoch为单位，因此将6秒因果窗口按其中点聚合到对应30秒epoch，且要求至少80%窗口通过质量规则。主要模型为带类别权重的多项Logistic Regression，Random Forest与线性SVM作为比较。所有评价严格按受试者留一，报告Macro-F1、平衡准确率、Cohen's Kappa、各状态召回率及按真实类别归一化的混淆矩阵。

为检验动态信息的增量价值，比较仅静态区域PSD特征与加入过去1分钟斜率的Logistic Regression。部署状态模型使用与论文评价相同的30秒聚合特征；实时端以过去30秒滚动窗口每3秒更新一次W/N1/N2概率。

## PSD阶段生理解释

对每名受试者分别计算W、N1和N2阶段的区域对数频带功率均值，进行W–N1和N1–N2受试者内配对比较。主要指标包括额区beta、枕顶alpha、中央theta、中央sigma和额中央delta；报告Cohen's dz、bootstrap 95%置信区间及FDR校正结果。该分析用于判断分类和预测是否符合已知的清醒节律瓦解、低频同步增强及N2纺锤相关sigma活动建立。

上述结果属于与状态转变一致的观察性神经生理特征，不能证明头皮频谱变化与入睡之间的因果机制。尤其额区beta可能受肌电影响，sigma和纺锤波与N2评分定义存在生理关联，解释时均需明确边界。

## 第二阶段流式接口

第二阶段提供两条路径：处理后特征的历史JSONL回放，以及直接接收连续16通道原始EEG的数据块接口。原始信号经过平均参考、有状态因果IIR滤波、6秒环形窗口和过去60秒斜率计算，每3秒输出：

- 信号质量；
- 未来5分钟进入稳定N2的概率；
- W、N1、N2状态概率；
- 额区beta、枕顶alpha、中央theta及alpha/theta变化斜率。

实时数据契约固定输入采样率、通道名、单位、时间戳和二维样本矩阵，输出契约固定状态、概率、信号质量及解释性特征。默认音乐控制器返回无操作命令。工程原型另定义高觉醒W、放松W、N1过渡、微觉醒修复和N2保护五种听觉控制模式；每30秒对平滑状态进行一次决策，使用连续确认、最短驻留和冷却时间避免频繁切换。音乐生成在会话前或后台异步完成，实时关键路径只进行缓存选曲、交叉淡入、短音效叠加和N2淡出。五种模式是待实验验证的控制假设，不属于新的睡眠分期，也不构成本数据集中的干预结果。

## 研究边界

本阶段验证健康成人入眠动力学、16通道特征可解释性、W/N1/N2内部交叉验证性能和记录起点连续预测可行性。由于所有结果仍来自同一公开队列，尚无外部数据验证。数据不包含音乐干预、失眠患者或同一受试者的多夜重复记录，因此本阶段不评价音乐疗效、失眠诊断性能或个体跨夜稳定性。
