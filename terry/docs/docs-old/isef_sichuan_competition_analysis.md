项目创新性与竞争力分析

本项目不是普通的睡眠分期模型，也不是简单地根据脑电播放音乐，而是围绕入眠这一连续转变过程，同时回答三个问题：受试者现在处于W、N1还是N2；未来5分钟是否会进入稳定N2；哪些区域频谱变化与这一转变一致，并据此构建只在必要时切换、在N2后主动停止干预的五模式低干扰音乐控制原型。

项目使用ANPHY-Sleep公开多导睡眠数据。

项目已经完成四层研究工作。

第一层是入眠神经生理描述。临近首次稳定N2时，额区beta下降、枕顶alpha衰减、中央theta上升。首次稳定N2之后，多数受试者的中央睡眠纺锤波明显增加。

第二层是W、N1、N2三分类。数据集共得到1266个有效epoch，其中W为579个、N1为282个、N2为405个，受试者均包含三个状态。

动态多项Logistic Regression在按受试者留一验证中的平衡准确率为0.774，Macro-F1为0.746，Cohen’s Kappa为0.675。W、N1和N2召回率分别约为0.805、0.689和0.829。N1最难识别，这与N1本身边界模糊、评分一致性低的特点相符。

第三层是未来稳定N2预测。主分析重新从每段记录的起点建立连续特征流。动态EEG模型的受试者级平均AUC为0.821，95%置信区间为0.778–0.863，平均精确率为0.728。目标5分钟事件检出率为89.3%。

第四层是流式工程原型。系统能够接收连续16通道脑电数据块，保持因果滤波状态，每3秒更新一次特征和概率，并以过去30秒滚动特征输出W、N1、N2概率。模型输出与音乐系统之间解耦。

音乐端定义五种控制模式：高觉醒W降刺激、放松W稳定、N1低显著性过渡、微觉醒修复和N2睡眠保护。策略每30秒做一次决策，要求连续确认，。音乐生成用于会话前或后台异步生成候选音乐；实时关键路径执行缓存选曲、交叉淡入、短音效叠加和N2淡出。


本项目目前结论是：

预设16通道EEG能够在健康成人公开队列中捕捉与W–N1–N2转变一致的区域频谱变化，并在按受试者留一的内部验证中实现当前状态识别和未来5分钟稳定N2预测；基于这些输出可以构建一个事件驱动的音乐控制原型。

PSD阶段分析进一步给出可解释证据。

W到N1过程中，额区beta显著下降，Cohen’s dz约为−1.29；枕顶alpha显著下降，dz约为−1.11；中央theta显著上升，dz约为1.74；中央sigma小幅上升；额中央delta变化不显著。

N1到N2过程中，中央theta继续上升，dz约为1.88；中央sigma显著上升，dz约为1.85；额中央delta显著上升，dz约为1.96。枕顶alpha在N1达到较低水平后于N2出现部分回升，说明alpha不是简单单调下降指标。N1到N2的额区beta变化经FDR校正后不显著。



项目的创新

常见睡眠AI项目只回答当前属于哪个阶段。本项目把问题拆成两个互补任务：三分类回答“现在在哪里”，未来N2预测回答“正在向哪里发展”。这种状态与转变双任务框架比单纯提高分期准确率更闭环。

创新在于重新定义了适合入眠控制的研究目标。对于音乐系统，知道当前是N1还不够，还需要知道稳定N2是否正在临近，从而提前降低听觉显著性并在进入N2后停止输出。

项目不把黑箱准确率作为唯一结果，而是用区域对数PSD、变化斜率、地形图和纺锤波证据解释W–N1–N2转变。可以直接看到每个模型输入的生理含义，而不是只看到一组神经网络参数。

大量AI音乐项目强调生成更多内容，本项目把闭环定义为减少不必要输出。高觉醒W、放松W和N1过渡使用不同低显著性音乐策略；微觉醒只叠加短音效；N2保护模式优先淡出或静默。



本项目的问题清晰且可以检验：

第一，16通道EEG能否识别W、N1、N2；

第二，能否预测未来5分钟稳定N2；

第三，PSD变化是否与状态转变一致；

第四，能否把模型结果转化为低干扰、事件驱动的音乐控制原型。


项目不仅有概念图，也有可以运行的程序、明确的数据结构、错误回退和结果复现命令。


与“用脑电判断睡眠阶段”的项目相比，本项目增加了未来转变预测和事件级提前量。

与“用深度学习做睡眠分期”的项目相比，本项目强调可解释模型。

与“根据脑波生成音乐”的项目相比，本项目没有把连续PSD数值直接拼接成Prompt，而是通过有生理边界的状态机降低调用频率，避免模型抖动。
