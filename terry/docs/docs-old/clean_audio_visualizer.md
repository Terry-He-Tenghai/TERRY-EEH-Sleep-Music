# 简洁界面与音频变化可视化

## 2026-09-19

主分轨面板已收敛为：来源状态、曲目/播放时间、W/N1/N2或演示阶段、实时混音波形/频谱、四个声部节点、变化强度/对照/音量。复杂诊断、模型说明、参数和日志放入“诊断与说明”。

实时图来自浏览器最终混音节点的 AnalyserNode：波形为最近约64ms、固定×8显示；频谱为0–8kHz的32个峰值柱；右上角为数字RMS dBFS。它显示浏览器数字链路，不是声压或听感测量。声部参数图显示节点增益目标，不等于实际响度。

自适应增强不再只使用原计划增益：变化强度默认85%，对有效/动态演示计划把控制量先经过平滑曲线，再向更宽的角色目标插值：钢琴约1.5%–85%、低音约1%–41%、弦乐约5%–70%、铺底约4%–62%，并扩大低通亮度范围。参数变化不改变主输出音量。固定分轨对照将已选四轨固定为0.3节点增益，便于比较，但不包含未选原曲声部，也未做等响度校准。

强烈的声部差异不等于助眠效果；前台播放、设备音量、原曲内容和浏览器压缩都会影响听感。保守模式不应用扩大对比，避免低质量信号被放大成音乐状态变化。动态演示仍明确标记为预设，不是模型分类。
