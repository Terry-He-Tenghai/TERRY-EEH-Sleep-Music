# 三条件交叉实验：参数与分析口径

依据：`docs/docs-new/9.27EEG-Adaptive Music Engine Experimental Design(1).docx`。
本文件说明应用已实现的数据管理与探索性分析，不替代伦理审批、冻结版实验方案或统计分析计划。

## 1. 数据归档

统计单位为参与者，推荐使用 P001、P002 等去标识编号，也支持中文姓名（本地敏感信息）。同一姓名或编号下，每种条件可保存多个 UUID 独立会话，重复序号按“参与者 + 条件”自动递增，不覆盖历史记录。

| 代码 | 后台条件 | 实际干预 |
| --- | --- | --- |
| A | fixed | 外部设备播放固定音乐；本机仅采集、分析和保存 EEG，不启用本机音乐或自动 SongEval |
| B | sham | 独立预设演示信号驱动音乐；当前实测 EEG 另行采集保存，不参与音乐更新 |
| C | closed_loop | 当前合格 EEG 驱动的真实闭环 |

开始前通过“输入受试者姓名”选定身份，再选择 A/B/C。采集中锁定身份和条件。新会话保存 `execution_version=1` 和实际控制来源，执行条件不可事后改写；问卷、审核状态和备注仍可补录。旧会话标签仍可修正，但标签不能证明实际执行过对应策略。六种顺序为 ABC、ACB、BAC、BCA、CAB、CBA。保留中断、退出、排除、失败和未分组记录。

方案目标为 18 位完成者，最多随机 24 位；三个访问间隔至少 24 小时，尽量处于相同时段。每次准备不超过 15 分钟，静默基线 5 分钟，睡眠机会 45 分钟，问卷 5 分钟，拆卸与清醒检查 10 分钟。后台的开始时间可用于核查访问日期；顺序、间隔和协议偏离仍需研究人员审核。

## 2. 需要分析的参数

| 类别 | 参数 | 来源、口径 |
| --- | --- | --- |
| 主要主观结局 | LSEQ GTS 三个条目与平均分 | 导入冻结版问卷已正确计分的 0–100 分值；三个条目全部存在才计算均值。必须预先统一方向，应用不提供或改写问卷题干。 |
| 主观结局 | 放松 VAS 0–10 | 实验后手动录入；0 是有效评分。 |
| 主观结局 | KSS 前、后 1–9 与后减前 | 前后评分单独保留；方向仅为描述，不自动解释为更好。 |
| 主观结局 | SUS 10 条目、总分 0–100 | 保存原始 1–5 回答；奇数题减 1、偶数题用 5 减回答，求和乘 2.5。缺任一题不计算总分。使用授权、验证过的问卷版本，不自行改写题干。 |
| 补充主观指标 | 音乐过渡自然度 VAS 0–10 | 独立于 SUS，不将过渡评分冒充系统可用性量表。 |
| 补充主观指标 | 入睡困难 VAS 0–10、盲听舒适度与音乐性 1–7 | 补充指标，不能替代方案的主要结局。 |
| 生理 | 心率、HRV | 由外部硬件及其流程负责；本次不扩展心率功能，前端分析指标不展示 HR/RMSSD。历史导入格式仅保留兼容。 |
| 活动 | 首次连续 5 分钟低活动的潜伏期 | 预设活动阈值及最大采样间隔；从干预开始到该连续段起点，秒。缺失或断流打断连续段；无事件不填 45 分钟、不填 0。未检测到与完整观测下无事件不等价，正式删失分析另行处理。 |
| EEG | α、θ 绝对功率与相对功率变化 | 质量合格的原始 40 秒窗口 Welch 功率，跨记录通道平均；新 α 指标为 8–12 Hz，θ 为 4–8 Hz，相对功率以 1–30 Hz 为分母。旧 α 8–13 Hz 指标保留，不能混用。基线差值仅纳入完全处于人工标注阶段内的窗口；缺阶段或缺功率则留空。 |
| 音频 | RMS Change | 已上传最终数字混音的相邻分块 RMS dBFS 绝对变化均值；不是 LUFS、不是扬声器声压。音频时钟未核验对齐，不冒充“45 分钟干预内”指标。 |
| 控制 | Fallback Proportion | C 使用实测控制事件，B 使用单独的脚本控制事件，A 不适用。干预内已观测 ready/frozen 间隔中 frozen 所占时长；超过 12 秒间隔不推定状态，分母与观察范围另存。不是完整断流/伪迹覆盖率。 |
| 工程 | 后端 CPU、进程峰值 RSS | CPU 为会话内进程 CPU 时间除以墙钟时间，单核 100%；RSS 是后端进程生命周期峰值 MiB，非会话专属峰值。不包含浏览器、远端 GPU 或整个设备，不据此宣称已验证树莓派性能。 |
| 工程 | 合格窗口比例、分类耗时、播放错误、下载/解码耗时、录音覆盖 | 沿用会话报告。分类耗时不是端到端或实际扬声器延迟；录音/会话时长比不证明完整覆盖。 |
| 混杂与安全 | 前夜睡眠小时、咖啡因 mg、用药、耳位实测 dBA、不适/不良事件 | 手动记录，不从数字音量推定 SPL；备注不包含身份信息。 |

## 3. 数据录入与缺失

实验结束后进入“管理 · 实验”，搜索姓名或编号，筛选固定/伪闭环/真闭环，勾选一个或多个记录。逐记录指标、条件统计和配对图使用同一筛选范围；未勾选时分析当前筛选的全部记录。通过“查看／标注”补录阶段边界、问卷、安全记录及完成/核验状态，查看完整 JSON、音频和原始 EEG 目录。采集失败也保留已关联的身份。

阶段边界均为从 EEG 会话开始计算的秒数。当前页面从点击开始起记录 2700 秒，不自动插入 5 分钟静默基线，不能把已播放音乐的前 5 分钟标为静默基线。若协议要求连续基线加干预，需要另行实现并冻结阶段控制（API 允许指定 60–10800 秒总时长）。不能填入未实际采集的区间，默认不代填。两端必须完整、结束大于开始，基线与干预不得重叠。

体动导入采用本地 UTF-8 CSV，列为 `time_s,motion`，允许标准引号与 BOM；时间必填且严格递增，活动值空白为缺失。活动单位由设备决定，阈值必须匹配且预先冻结。导入会替换该会话已有生理数据，需保留原始设备导出。历史 HR/RR 字段仅作兼容，当前 UI 不提供心率分析流程。

缺失始终保留为空，不做插值，不用 EEG 替代体动或外部心率。A 的外部音频未被本机记录，RMS、音乐性 AI 评分等不填零。原有盲听音乐性 1–7、舒适度、AI 评价与 SongEval 五项原生 1–5 分全部保留。浏览器混音录制上限 360 MiB，48 kHz 双声道 float32 约 16.4 分钟，达到上限会标记部分录音，不能作为完整 45 分钟音频证据。

## 4. 个体与整体可视化

“脑电频段功率偏移”独立显示在记录列表与总指标表之间，沿用受试者、条件筛选和多记录勾选范围。每条记录显示整段合格窗口的 Alpha 8–12 Hz、Theta 4–8 Hz 平均绝对功率，以及两频段的基线、干预绝对/相对功率和干预减基线差值。相对功率以百分比显示，差值为百分点（例如 20% 到 25% 显示 +5 个百分点），不是相对增幅。保留后端原始比例口径，不改变 CSV 或三条件统计。缺阶段、缺已记录的合格功率、阶段功率不完整及非设备来源分别提示，可通过“阶段标注”进入原有标注表。不会用旧 Alpha 8–13 Hz 代替新口径，也不根据整段均值伪造前后差值；该视图不是完整 PSD 曲线或节律过渡速度检验。

“三条件对比”中选择指标和对比对象：整体显示每位用户的三条件配对连线；选择一个匿名编号时只显示该用户 A/B/C 与纳入会话数。缺失点不连线，数据表提供准确值。

整体统计先在每位用户、每种条件内平均合格重复会话，再计算人数、均值、样本 SD 和中位数。10 位完整用户对应 10 个三条件配对，不是 30 个独立样本。会话级工程描述表是另外的诊断视图，不是主要受试者级分析。

纳入规则：设备模式、已结束、人工标为已完成、实际条件已核验，且非采集/推理/异常结束。未审核、失败、退出、排除、运行中和默认演示会话不进入结局分析；记录仍保留。每项指标的 n 按有效值单独计算。三条件完成数量表示会话齐全，不意味着所有指标齐全。

探索性统计：至少 3 位具有完整指标的用户可计算 Friedman 三条件检验；至少 3 对可计算 C−A、C−B Wilcoxon 配对检验。配对 p 值在所有可计算指标与两个比较组成的同一检验族中做 Holm 校正。Friedman p 为未校正探索性结果；小样本近似 p 的可靠性有限，不自动给出显著性或助眠结论。最终分析应按冻结的主要/次要结局、序列和周期效应、缺失处理计划执行，不事后挑选显著指标。

## 5. 当前边界

**新记录的 A/B/C 会执行不同策略，旧标签仍不等于执行证据。** B 使用 `showcase-96s-v1`：W/N1/N2/W 各 24 秒循环，由独立合成数据队列驱动；实测 EEG 存于 `windows` 和原始 CSV，脚本控制另存 `control_windows`，不混入生理结果。演示数据源仍可用于台架测试，但默认排除正式分析。

已分配实验到 2700 秒结束，也可手动停止；两个 N2 不再提前结束 EEG 记录，真闭环原有 N2 暂停音乐策略仍保留。无实验分配的旧 API 会话保留原有 N2 自动结束规则。B 的预设演示轨迹并非历史受试者的冻结轨迹，ACE 在线生成仍可用，因此仍与原 DOCX 的历史轨迹/禁用在线生成方案不同，正式实验前必须修订并冻结方案。

模型分期不是临床睡眠分期，低活动潜伏期不是经 PSG 证实的入睡时间。实际端到端延迟、完整控制回退覆盖、统一量表方向、运动阈值和同步误差需另行验证。当前分析不建混合效应模型、不校正周期/序列效应、不做正式删失生存分析。

报告在 `backEnd/session_reports/`，原始 EEG 在 `backEnd/recordings/`，均本地保存且排除 Git。报告记录对应原始目录，文件名使用随机 ID 而非姓名。姓名会进入本地报告、元数据及 CSV，属于敏感信息，需限制访问、独立备份并遵循同意/去标识流程。仅在本机回环地址使用，管理页不带认证；ACE/SongEval 不接收姓名、EEG 或问卷。
