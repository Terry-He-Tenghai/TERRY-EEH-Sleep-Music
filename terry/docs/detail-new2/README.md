## 当前版本的关键事实

- 网页支持 A 固定音乐、B 伪闭环、C 真闭环。A 使用外部设备播放，B 用独立脚本信号控制音乐，C 用当前采集 EEG 控制音乐。
- 真实设备路径使用研究型波形 CNN，输出 W/N1/N2；不是旧版 11 特征的未来 N2 逻辑回归主链。
- 实际采集保持 16 路；2/4/6/8/16 是分类模型选择，不是采集通道数量切换。
- 命名 A/B/C 实验强制保存原始 EEG。后台支持同一受试者同一条件的多次记录、筛选、评分及对比。
- 连续三个有效 LIVE N2 后音乐用 30 秒淡出，EEG 记录继续。不是“两次 N2 就结束实验”。
- 已有 EEG Alpha/Theta 绝对与相对功率、探索性配对统计、数字音频指标、盲听音乐性与可选 SongEval。
- “旧代码”包含仍被当前 DEMO 和音乐生成原语复用的部分；未挂载组件、保留 API、共享依赖和不可达历史分支必须分开判断。

## 证据边界

源码中明确保留 `experimental`、`hardware_validated=False`、`probabilities_calibrated=False` 等标记。实现闭环不等于证明助眠有效，也不等于临床睡眠分期已验证。分类耗时不是端到端声学延迟；浏览器 PCM 不是扬声器回采；数字增益不是耳边声压；AI 音乐评分不是参与者评分。

本轮文档编写进行了源码调用核对和文档链接检查，没有进行实际人体实验、设备采集、远程音乐生成或完整回归测试。文档中的验收步骤是待执行的操作清单，不是已完成的实测结论。
