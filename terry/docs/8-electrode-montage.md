# 8 电极采集与模型迁移（历史方案，已停用）

当前网页真实设备采集已恢复全部 16 路，以下八电极关闭方案不再是当前行为。网页逐路滤波仅用于显示；分类仍需匹配实际帽位的 16 通道模型，不能将另一套 16 通道模型按索引套用。

真实设备的通道顺序以操作者确认的 Cyton 帽位图为准：1 Fp1、2 Fp2、3 C3、4 C4、5 P7、6 P8、7 O1、8 O2、9 F7、10 F8、11 F3、12 F4、13 T7、14 T8、15 P3、16 P4。当前软件请求 16 路全部上电并送到显示和采集输出。采集前仍须核对帽位、参考和偏置电极及实际设备行为。

## 为什么旧模型不可直接沿用

`config.hardware.yaml`、实时 `SignalPipeline` 和现有模型均使用另一套 16 通道映射。即使数量同为 16，实际 `Fp1/Fp2/.../T7/T8` 帽位也不等于模型所需的 `C3/C4/Cz/.../Oz/O2`。当前真实设备可以采集并展示 16 路波形，但此帽位与现有模型不一致时分类和分类驱动的音乐切换仍被阻断；16 通道演示模式不变。

## 恢复自动分类的工作

1. 固定帽位、参考/偏置、电极接触检查、采样率与滤波参数，记录每次实验的通道映射和原始数据；先确认 8 路数据质量及设备关通道行为。
2. 在独立训练配置中将目标通道设为上述 8 路，重新定义区域特征（例如双侧额区和颞区的频带功率、相对功率与时间趋势），移除或重新设计全部后部/中央特征。同步更新离线提取、实时特征、质量判定和模型特征清单，确保训练/推理同构。
3. 收集与目标人群一致、有人工标注 W/N1/N2 的数据；按受试者划分训练/验证/测试，报告分期指标、校准、缺失电极和运动伪迹条件下的表现，并与原模型基线对比。若目标是预测未来 N2，还需独立验证提前量、误报与漏报。
4. 将新权重、配置和布局版本绑定；启动时校验通道顺序、采样率、特征清单与模型元数据一致后，才允许解除阻断。回到真实设备完成端到端回放与人工核验，再启用自动生成/播放。

滤波仅改变显示波形，不能修复电极接触不良、运动伪迹或不正确的帽位映射。
