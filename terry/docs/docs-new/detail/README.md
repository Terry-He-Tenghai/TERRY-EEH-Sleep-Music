## 最容易误读的变化

- 2/4/6路当前是Fp额区组合，C3/C4少通道权重是历史版本；采集和显示可以仍为16路。
- LIVE无需300秒个人基线，当前确认次数配置为1；模型窗口仍需要40秒。
- 合格窗Welch功率只作证据，不是恢复频谱分类兜底。
- 预设演示现在可以显式触发ACE演示生成，但不叫真实分类。
- 报告/录音/实验标签已实现；伪闭环输入自动执行和临床睡眠统计未实现。
- 质量差或过期可以保持已有音乐；连续有效N2自动结束、错误、手动停止等仍会停止，不是无条件连续播放。
- 当前App只有ACE与上传背景两个来源，四分轨后端和播放器源码保留但未挂载；旧分轨网页用例不能证明新页面仍有入口。
- 同源四轨只改变声部比例和低通；本地MIDI使用16拍调度，并不自动和原曲拍点对齐。
- `docs-old` 和旧会话进度保留历史，和当前源码冲突时以本文核查基线为准。

本轮不含新的实机测试或远端运行验收，测试结果须单独按运行时间和环境记录。
