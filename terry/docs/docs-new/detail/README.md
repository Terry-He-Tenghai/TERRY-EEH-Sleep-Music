## 一个贯穿全篇的例子

假设 16 个电极连续记录脑电。先确认接触、时间和单位，再在一小段信号上估计不同频率的强弱；用过去的变化与历史标注训练出的模型，估计“当前更像 W/N1/N2 中的哪一类”和“未来五分钟出现稳定 N2 的可能性”。如果信号可靠、个人基线已建立，音乐决策会综合多次估计，缓慢调整已准备好的分轨声音；如果质量不足，就等待、采用较弱的固定方案或停止。这个过程**不会自动证明**人的睡眠已经改善。

## 阅读时特别留意的三个区别

1. **预设演示 ≠ 模型预测**：演示中的状态变化可以用来理解音乐控制，不能当作模型识别的证据。
2. **四分轨调整 ≠ 编辑上传文件中的音符**：四路独立声音可以调比例；上传的是混合后的声音。目前上传背景上仍可能叠加另外生成的音符，这会改变听到的声音，但不改变原曲文件内部音符。
3. **信号处理改变 ≠ 旧模型自动有效**：[原文](../Untitled.md)部分段落以及[旧机器学习概念图](../Images_attachments/image%202.png)仍标有“0.3–45 Hz、无显式陷波”的旧处理方式；目前采用的条件是约 5–50 Hz 带通与 50 Hz 陷波。5 Hz 高通会明显削弱约 0.5–4 Hz 的 delta 活动，不能直接套用旧模型分数或以前对低频特征的解释。图片用于理解流程，不作为当前参数清单。要得出新配置下的性能结论，需要重新训练和验证。
