# 02｜采集、时钟、滤波和质量检查

更新：2026-10-07，依据当前源码。返回[主文档](../系统架构与功能.md)。

## 1. 电极、模型和显示是三件事

硬件BrainFlow配置完整16路并按 `channel_mapping.CAP_ORDER` 标记：Fp1/Fp2/C3/C4/P7/P8/O1/O2/F7/F8/F3/F4/T7/T8/P3/P4。软件帽位名称不能证明现场接线，特别是P7/P8不能改名冒充Fz/Cz。

2路模型索引0/1；4路0/1/10/11；6路0/1/10/11/8/9。前端 `modelChannels.js` 维护这一映射；`App.vue`仍接收和检查完整16路消息，绘图使用独立indices，默认显示所选模型电极，“查看全部16路”仅控制显示。勾选波形显示电极不改变分类输入。

8路为帽位前8路，却仍按旧训练契约检查全部16路；2/4/6额区仅检查所选路。采集数、分类数、可见数不能混用。

## 2. 设备线程

`app.py`懒加载BrainFlow，以CYTON_DAISY_WIFI_BOARD读取样本、硬件timestamp通道及package编号。采样配置250/500/1000Hz，增益1/2/4/6/8/12/24；启动指令配置所有物理通道。收到空批次短暂等待，连续10秒未收到数据触发采集异常，报告结束并停止。该硬件停止不同于短时分类等待时“保持已有音乐”。

样本计数除以采样率得到收到数据秒数；缺包时它不等于真实墙钟时长。report的duration_s是服务器开始结束墙钟差，不能自动理解为睡眠潜伏期。

## 3. 原始输入与显示输入分支

`_publish_chunk()`先将原始微伏，包括NaN/Inf，提交推理，再用 `DisplayFilter` 生成显示曲线。显示滤波与幅度裁剪不用于证明模型质量。显示约5–50Hz及50Hz陷波；CNN训练契约是0.5–35Hz带通和50Hz陷波，有平均参考和固定100µV缩放，必须区分。

`powerline_filter.py`保留独立工频滤波工具；不能仅因AcquisitionService实例化该对象，就宣称网页推理前已经使用它二次滤波。

## 4. 40秒窗口不是40秒计算耗时

LIVE累计40秒原始信号，因果滤波初始化后舍弃前10秒，只对最近30秒做分类；每1500样本（250Hz下6秒）检查一次，通常42秒出现第一个可用分数。当前确认次数1、分数门槛0.55，类别确认不是“两次N2自动结束”的计数。

如果希望更短的首次窗口，需要重新训练并评估短窗口契约，不应只截短/补零给现有权重。质量不合格本身也可能导致一直没有分数，不等于推理计算慢。

## 5. 质量门控

对模型所要求电极的原始40秒窗口：非有限值拒绝；最近30秒超过2个一秒片段标准差低于0.1µV判平直；滤波后峰峰值超过500µV判高幅；滤波后标准差低于0.1µV判低变异。先做所选质量与时间滤波，再所选平均参考、除以100µV进入CNN。这里的signal_quality=1代表全部要求电极通过门控，不是临床信号评级或准确率。

有限高幅/平直/低变异的完整坏窗口保留滚动缓冲，每6秒复检，坏片段移出后可恢复；NaN/Inf或连续性断裂清空重收集。无效窗口不输出伪造分类、不插值替代、不切回启发式频谱。

界面显示失败电极、finite、flat_seconds、filtered_ptp_uv、filtered_std_uv、quality_reason、buffer_retained和reset_reason。超大幅度需要核查参考、接触、增益、单位或ADC饱和，而不是简单提高阈值。

## 6. 连续性和积压

LIVE检查样本索引、rate、形状、有限硬件timestamp、倒退、循环包编号（mod256）和设备时间相对样本数量的偏差。最近约40秒偏差变化预算0.5秒用于容忍传输批次时间戳；完整256样本丢失也能通过时间差被发现，但现场驱动若掩盖时钟及计数缺口，软件不能保证检出所有丢包。

模型导入或计算期间队列满时，丢弃旧队列、保留新批次并重置分类/音乐控制历史；溢出后在途预测不能授权新控制。这样避免永久阻断，却不能保证持续性能不足时仍有分类。DEMO有独立更严格的重启策略。

## 7. Welch频带指标不是分类器

新 `waveform_classifier.py` 对合格原始40秒数据做4秒Welch段，alpha 8–13Hz、theta 4–8Hz、beta 13–30Hz积分，以每要求通道的µV²写入报告。用于观察/统计，不进入CNN作为分类特征，也未使用个人基线或完成生理解释验证。报告合格窗口比例是重叠窗口计数，不是有效数据覆盖时长；硬件丢包汇总目前仍为未测量。

历史 `features.py/preprocess.py/streaming.py` 的频谱特征与300秒基线，属于DEMO旧模型及离线工具，不能代替上述LIVE契约。
