# 05｜运行条件、模块交接与结果边界

[返回阅读导航](README.md) · 对应[原文](../Untitled.md)第 10–12 节。这里把原文的接口列表理解为**模块之间需要交换什么信息**，不列具体网址或程序文件，方便以后修改实现而不影响概念。

## 1. 每个模块交给下一个模块的是什么

|交接环节|送出的内容|接收方需要核对什么|
|---|---|---|
|采集 → 信号处理|16 个位置的电压序列、时间和采样频率|电极位置顺序、微伏单位、是否有缺样、信号是否连续|
|信号处理 → 特征描述|一段时间内的频段强弱、质量指标和变化趋势|分析窗的起止时间、有效通道比例、频段定义|
|特征描述 → 状态估计|同一顺序、同一含义的特征|是否与训练时采用相容的预处理、通道、单位和特征定义|
|状态估计 → 音乐决策|W/N1/N2 概率、未来稳定 N2 概率、个人基线与质量|概率是否可信，是否需保守、冻结或停止|
|音乐决策 → 音频播放|选哪份素材、音量比例、亮度与渐变时间|素材是否存在、计划是否新鲜、音频是否成功起播|

所谓“接口”就是两边对这些字段**含义**的共同约定。即使未来更换网页框架或通信地址，只要含义清楚，概念上仍是这些交接。如果把音频“计划已送出”误读为“声音一定播出了”，或把“电极接上”误读为“位置已核对”，结果就会失真。

## 2. 系统为什么需要几种不同的停止和降级方式

脑电采集是不稳定的现实过程：电极可能松动，样本可能中断，模型可能还在等待足够长的历史，音频文件也可能加载失败。因此并非只有“正常播放”和“出错”两个状态。

- **等待**：数据或个人基线还不够，暂不宣称已经有可靠的自适应依据。
- **保守播放**：仍有部分有效电极和可用音频，但不足以放心地根据睡眠估计大幅改编；用固定、较弱的声音保持可预期性。保守并非“证明安全”。
- **冻结或停止**：没有足够有效的输入、收到不连续数据、计划太旧、用户停止或播放环境中断，音乐不应继续当作最新判断在变化。

“坏通道补全”可以让研究流程在部分电极失效时继续，但用其他通道的平均数代替缺失通道**不能重建那个位置真正的脑电**。补全后的结果要与全通道完好时分开评估。[02](02-eeg-acquisition-signal.md)专门解释质量与补全。

## 3. 在自己电脑上运行也需要核对四类资源

1. **设备和接线**：物理电极位置与记录顺序须由操作者核实，电脑无法只凭通道名称发现贴错位置。设备标称采样率、实际记录时间和网络连通性分别确认。
2. **数据与模型**：离线训练需要有相应记录及可信的睡眠标注；实时推理需要与当前信号处理条件相适配的模型。更改滤波频段、参考或通道后，旧模型的结果不能自动继续引用。
3. **音乐素材**：四分轨需要四个来源、长度匹配且可被播放器解码的音频。只有项目说明文字并不代表音频文件已经安装。上传完整 WAV 则是另一类素材，不能当作已分离的四轨。
4. **浏览器与输出设备**：音频需要播放许可；页面关闭、切后台、扬声器未连接或设备音量为零，会改变听到的结果。数字增益限制并不能代替耳机声压测量。

本地原型的共享采集状态也意味着多个页面可以看到同一次采集；一个页面停止可能影响另一个页面。若将系统交给多人远程使用，需要重新设计账户、访问控制、数据隔离、审计和设备竞争处理，不能把本机可用当作公网可用。

## 4. 看见结果后，怎样避免四种常见误读

**误读一：“画出波形就能说明电极质量好。”** 画面为了便于观察可能去均值、压缩幅度；仍须检查平线、离群值、缺样、通道有效比例和时间戳。波形是否好看与分类器能否可靠工作是不同问题。

**误读二：“模型给出 80% 就等于 80% 的人肯定会睡着。”** 概率针对明确的训练标签和时间窗；是否准确还需要在未参与训练的人身上验证概率校准。例如把所有预测为 0.8 的情形放在一起，看真实事件是否约有 80% 发生，才接近“已校准”的含义。一次输出不能完成这个检验。

**误读三：“动态演示从 W 变到 N2，说明模型认出了 N2。”** 预设演示把人工设定的概率直接送进音乐控制。它适合看播放器反应，不适合报告分类准确率。

**误读四：“音乐跟着变化，说明能帮助入睡。”** 控制系统有响应，说明信息链可能接通；助眠效果需要独立的对照条件、睡眠指标和受试者设计。音频节点有数字信号也不能替代真实的听感/声压测量。

## 5. 怎样逐步验证整条链路

按由易到难的顺序，避免一次把“演示有效”“模型有效”“临床有效”混成一个判断：

1. **概念核对**：确认 W、N1、N2 与未来稳定 N2 标签含义一致，分析时间窗、时钟、采样单位明确。
2. **离线数据核对**：抽查记录与标注是否对齐；用未参与训练的**受试者**作验证而不是打乱重叠小窗口。[03](03-ml-training-inference.md)解释原因和指标。
3. **信号链核对**：在设备上检查电极物理映射、参考方式、工频环境、采样连续性、异常通道和补全情况；对照离线/实时数据的特征分布。
4. **模型适配核对**：更新滤波或其他前处理后重新训练并独立评估；核对不同人、不同设备以及异常通道条件下性能，不沿用旧版本分数。
5. **音乐链核对**：逐项测试缓冲、开始/停止、过时计划、断网、切后台、长时间播放、上传背景上额外声音和四轨对照；做听感与声压评估。
6. **效果研究**：设置合适的对照、定义终点和参与者条件，才评估对入睡、睡眠结构或主观体验的影响。模型概率和播放日志本身不是效果证据。

例如 5–50 Hz 的带通滤波会减弱 5 Hz 以下的活动。若训练时曾使用不同的频段，delta（约 0.5–4 Hz）特征就可能发生系统性变化；就算训练和实时采用相同的特征名称，也不能保证旧模型仍可靠。对此应记录配置、重做训练与评估，而不依据公式想当然地宣称性能不变。
