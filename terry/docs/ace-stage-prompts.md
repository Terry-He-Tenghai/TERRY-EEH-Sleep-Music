# ACE-Step 阶段音乐提示词

自动生成使用 `backEnd/ace_music_prompts.py`，以 M1、M2、M3 对应 W、N1、N2 音乐方案。所有生成请求先加入睡前放松、支持睡眠、轻柔起音和避免突发大音量的共同提示。连续三次有效 LIVE N2 后，用 30 秒逐渐淡出音乐，脑电采集继续；演示信号不触发真实 N2 暂停。N2 提示词适用于尚未触发暂停的 M3 或演示。

生成音频播放前按数字 RMS 与采样峰值进行衰减，不放大安静音频；启动与换曲使用 8 秒渐变。此保护不等于耳位声压限制，也不能保证音乐具有临床助眠疗效。手动停止与严重故障仍可立即停止。上传音乐完成 N2 淡出后需手动重新启用；生成音乐获得新的有效非 N2 分类后可渐入恢复。

## 共同音乐骨架

普通生成在提示词及 ACE-Step 参数中指定 60 BPM、4/4。默认 C 大调，八小节循环为 Cmaj9 → Am7 → Fmaj7 → C6，每个和弦两小节。用户可以选择大调、自然小调、和声小调、旋律小调及各自四组和弦进行；整个会话 W/N1/N2 沿用同一选择。大调以 C 为主音，小调以 A 为主音。首尾以轻柔主和弦连接，便于循环和跨曲衔接。终止式随所选和弦进行变化，属到主的终止仍保持克制，不制造强烈推进。

前后端共用 `terry/music_harmony.json`，避免显示的罗马数字、实际和弦与生成指令不一致。默认进行不变；例如大调提供 I–vi–IV–I、I–V–vi–IV、I–vi–ii–V、I–IV–V–I，自然小调提供 i–VI–iv–i、i–VI–III–VII、i–VII–VI–v、i–iv–v–i。和声小调保留升七级并使用大属和弦；旋律小调采用古典上行升六七级、下行还原的定义，和声用上行形式，提示词限制下行自然六七级与大 IV/V 和弦的冲突。

自动采集和手动生成均提供调式、和弦进行下拉选择；自动采集开始后不能更改和声选择，需停止后重新开始。参考音乐改写时隐藏和声选择，保留原曲和声。

上传参考音乐改写时不强制上述速度和调性，而是要求保持原曲节拍、速度、调式、和弦与和声节奏。系统没有自动测量原曲 BPM、调性或和弦，因此这是生成指令，而不是分析结果。

## 阶段区别

| 内容 | W / M1 | N1 / M2 | N2 / M3 |
| --- | --- | --- | --- |
| 节拍与速度 | 4/4，60 BPM | 保持相同，不实际减速 | 保持隐含节拍网格，不实际改成无拍号 |
| 音符节奏 | 四分、二分，偶尔成对八分 | 二分、全音符，2–4 拍休止 | 跨小节延音 |
| 律动 | 轻微暗示第 1、3 拍，无鼓组 | 半速听感，弱化重拍 | 无显式脉冲、节奏低音或震音 |
| 旋律 | 4–6 音动机，问答短句，一八度内 | 新的 2–3 音动机，五度内，每四小节短句 | 无前景旋律，最多每八小节两音呼应 |
| 和声 | 3–4 音和弦，柔和根音 | 2–3 音骨架，保留共同音 | 共同音持续，和弦色彩缓慢融合 |
| 音色与包络 | 圆润起音，轻柔衰减，p 力度 | 更暗更柔起音，长释放，pp 力度 | 极柔起音和长共鸣，pp–ppp 力度 |

## 风格对应

- 氛围：正弦为主、低通三角波辅助的合成器铺底；旋律也用柔和合成音，不引入钢琴主奏。
- 钢琴：全阶段保留柔音独奏钢琴，W 为清晰旋律，N1 为孤立短句，N2 为稀疏和弦共鸣与踏板尾音；波形描述使用自然琴弦泛音及衰减，不强行套用电子振荡器。
- 自然：持续小雨与远处柔风，加低电平正弦/三角音色；保持自然声音电平，不用雷声、鸟鸣或骤变声制造对比。
- 弦乐：弱音室内弦乐、柔和连弓；W 中提琴短旋律，N1 稀疏呼应，N2 弦乐长音；避免拨弦、震音和戏剧性渐强。
- 电子：正弦低音与低通三角主音，W 轻脉冲，N1 稀疏半速听感，N2 长音；避免鼓组、侧链抽吸、尖锐锯齿/方波和 drop。

## 切换与限制

自动生成传递目标 `music_state` 和当前可听方案 `previous_music_state`，提示词要求新曲在前两小节逐渐呈现新阶段特征。前端新旧音乐采用 8 秒线性交叉淡化，生成等待期间仍按原有规则保留已有音乐。阶段缓存共用同一音乐骨架，因此反向切换也保持相容。

差异主要来自动机轮廓、旋律密度、发音方式和延音比例，而不是骤降速度、换调或改换乐器类型。波形、动态和自然音细节是生成目标，不是确定性 DSP 控制。模型不保证精确遵循所有乐理约束；当前没有生成后节拍/和弦/响度自动校验，也没有采样级拍点或和弦同步。8 秒淡化减少突兀感，但不等于严格的 beat matching。需要真实生成后试听确认，不宣称临床助眠疗效。
# 可选音乐流派

自动采集与手动生成均支持 `music_genre`：`classical`（古典）、`jazz`（爵士）、`folk`（民谣）。默认不选，API 省略或传 `null` 都不追加流派提示词，保持原有生成方式。流派独立于氛围、钢琴、自然、弦乐、电子等音色选择，不替换所选乐器。

古典使用克制的乐句呼应、连奏与动机变化；爵士使用安静抒情曲式与柔和和弦声部，不强制摇摆、鼓组或重新配和声；民谣使用简单歌唱性旋律与温柔重复伴奏，不强制吉他或人声。所有流派保留所选调式、和弦进行与阶段密度规则，上传改写保留原曲音乐框架；同一会话的 W/N1/N2 共用流派，开始新会话时清空旧缓存。
